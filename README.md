\# 📊 保理公司 HR 薪酬自动化核算系统 (HR Payroll Automation)



\## 📖 项目背景 (Why)

在保理公司，薪酬核算极其复杂：不仅包含底薪，还涉及复杂的业务提成、风险准备金延期支付、合规一票否决扣款等。传统的人工 Excel 算薪方式耗时耗力，且极易因数据口径不一（如列名不统一、脏数据）导致算错。

本项目旨在打造一套\*\*轻量级、高可用、防合规风险\*\*的自动化算薪工具。



\## 🧠 核心设计思路 (Design Thinking)

本项目的设计核心是“输入 -> 标准化 -> 处理 -> 输出”的四步流水线：

1\. \*\*输入层 (Input)\*\*：负责接收系统导出的原始数据，定义唯一的入口，避免数据混乱。

2\. \*\*标准化层 (Standardize)\*\*：核心壁垒。解决不同部门导出的数据表头不一致、格式混乱的痛点。

3\. \*\*处理层 (Process)\*\*：核心算薪逻辑。负责汇总考勤、计算提成、扣款风险准备金。

4\. \*\*输出层 (Output)\*\*：负责生成面向管理层的多 Sheet 决策报表。
